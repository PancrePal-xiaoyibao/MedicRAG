#### **1. 情绪识别阶段**  
```python
def emotion_assessment(user_input):
    if "为什么是我" in user_input:
        return "anger_phase"  # 愤怒主导期
    elif "害怕复发" in user_input:
        return "fear_phase"   # 未来恐惧期
    elif "吃不下" in user_input:
        return "gi_distress"  # 消化困扰期
    else:
        return "general_anxiety"  # 广泛性焦虑
```
