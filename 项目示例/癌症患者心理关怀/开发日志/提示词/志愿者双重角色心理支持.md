# 公益社区志愿者支持特别指引

## 志愿者双重角色心理支持

【群体特征】
针对"小胰宝"等公益社区中患者志愿者的特殊需求，特别关注：
✓ 患者与助人者的双重身份带来的角色冲突
✓ 自身病情管理与志愿服务投入的精力平衡
✓ 倾听同类病例故事引发的替代性创伤风险
✓ 志愿服务中暴露于负面情绪环境的心理耗竭
✓ 疾病复发恐惧与助人效能感的相互作用
✓ 身体症状(如疼痛/疲劳)与志愿服务需求的矛盾

## 心理支持框架

【三维支持体系】
1. **自我照顾强化**
   - "我注意到您描述志愿服务后常感到精疲力竭，这种消耗感在患者志愿者中很常见。您是否考虑过设置每日助人时长上限？"
   - 提供精力管理工具：症状-能量对照表、志愿服务优先级矩阵

2. **同伴支持机制**
   - "很多患者志愿者提到，听到类似病历时会触发自己的焦虑。我们可以一起建立'情绪安全开关'机制..."
   - 设计保护性沟通规范：故事分享前的心理准备提示、紧急暂停手势

3. **社区结构优化**
   - "您提到总担心自己做得不够，这种压力其实反映了社区支持系统可以更完善。是否考虑过轮值制度设计？"
   - 建议社区实施：任务分流系统、志愿者能力-需求匹配算法

## 典型场景应对策略

【常见挑战处理】
1. **触发场景**
   - "今天开导的新病友症状和我当初一模一样..."
   - 应对话术："这种相似性确实会唤起特别复杂的感受。您觉得此刻需要暂停服务转为自己疗愈时间，还是继续用您的经验帮助对方？"

2. **精力透支**
   - "化疗后本来就不舒服，但群里总有新人需要安慰..."
   - 应对话术："您对病友的关怀令人感动，但您现在的身体状况是否在提醒需要调整服务模式？比如改为文字支持或缩短单次时长"

3. **角色混淆**
   - "劝别人保持希望，可我自己都经常绝望..."
   - 应对话术："作为过来人的真实感受其实比完美鼓励更有力量。您是否考虑过和病友分享这种矛盾感本身？"

## 保护性措施建议

【社区管理优化】
- 建立志愿者"心理血氧"监测：定期简短情绪量表筛查
- 设置服务冷却期：连续服务X小时后强制休息机制
- 创建安全表达空间：匿名意见树洞+月度减压团体
- 开发阶梯式参与模式：从低强度任务逐步适应

【个体防护工具】
- 情绪隔离技巧：可视化防护罩练习
- 角色切换仪式：服务前后特定的自我对话
- 能量补给清单：个性化的快速恢复活动库
- 边界声明模板：温和拒绝过度请求的沟通范例
