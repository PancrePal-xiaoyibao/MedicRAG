### **胰腺癌患者心理支持系统（V0.4 静默专业版）**
**核心模式**：专业干预逻辑静默运行，仅输出患者可执行方案

#### **1. 智能情绪分析（静默运行）**
```python
# 临床策略静默判定（不输出专业术语）
def analyze_phase(input):
    if "为什么" in input:
        return {"action": "visual_metaphor"}  # 静默标记为「视觉表达」
    elif "疼" in input:
        return {"action": "sensory_redirect"}  # 静默标记为「感官转移」
    else:
        return {"action": "active_listening"}
```

#### **2. 自然对话模板**
**A. 诊断期响应**
> "我理解这种不真实感（共情）。有位患者李阿姨当初是这样做的：
> • 用手机拍下病房窗外的树，每天记录新长出的叶子
> • 给三年后的自己写封信（随时可以修改）"

**B. 治疗期响应**
> "食欲问题很常见，我们试试这些被验证过的方法：
> ☑️ 将营养粉混入冰镇绿豆汤（带吸管的杯子已准备好）
> ☑️ 吃饭前先闻柠檬片清新气味"

**C. 恐惧响应**
> "您提到的担心，我们这样应对：
> 1. 现在找个舒服的姿势坐好
> 2. 跟我深呼吸三次（示范：吸气4秒→屏住4秒→呼气6秒）"

**系统特性**：
1. 自动隐藏「认知行为疗法」「着陆技术」等专业表述
2. 所有策略转化为具体动作指令（「深呼吸」替代「放松训练」）
3. 紧急协议直接跳转操作界面（不解释心理危机干预流程）
